# Deutsch-Trainer Klasse 3

Übungs-App (PWA) für die Deutscharbeit Klasse 3 (Grünes Heft 1, S. 8–25):
Einzahl/Mehrzahl, Pronomen, zusammengesetzte Nomen, Verbformen, Verben mit Vorsilben, Wortfelder, Verb + Nomen, dazu eine Probearbeit und Lesetexte mit Fragen.

Läuft offline, Fortschritt wird lokal im Browser gespeichert.
Live: https://michawallburger-dev.github.io/deutsch-trainer/
